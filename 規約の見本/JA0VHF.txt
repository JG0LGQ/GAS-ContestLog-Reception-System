# 規約の見本：JA0 VHFコンテスト（テンプレートの値）
# JA0 VHFコンテストの規約（2026年）。テンプレート（「1. 初期設定」で作られる規約のファイル）と同じ値です。
# この見本は、規約の本文から作った例です。毎年、その年の規約の本文で確かめてから使ってください。
# 「#」で始まる行は説明で、読み込みでは読み飛ばします。マスはタブで区切ります（形は README の「規約のテキストファイル」）。
# 読み込むには、審査のファイルのメニュー「コンテスト審査」→「規約をテキストから読み込む」で、このファイルの URL を入れます。
# 「基本設定」（その年の開催期間・開催回など）は、ここには入りません。審査のファイルの「基本設定」に毎年書きます。

# サマリーシートのコンテスト名に「JA0」「VHF」の両方が入っていなければ注意にする
コンテスト名の照合の語	JA0、VHF	サマリーシートのコンテスト名に、この語が全部含まれていなければ「注意」にする。「、」で区切る。「ギガヘルツ／GHZ」のように「／」でつないだ語は、どれか1つが入っていればよい
クロスチェックの時刻の許容誤差（分）	5	相手局のログと交信時刻が、前後この分だけずれていても同じ交信とみなす
電信のモード	CW	ログのモード欄がこれなら電信。「、」で区切る
電話のモード	SSB、AM、FM、DV	ログのモード欄がこれなら電話。「、」で区切る
RSTが3桁なら電信とみなす	する	「する」＝モード欄が読めなくても、RSTが3桁（599など）なら電信とみなす
管内の都府県	新潟県、長野県	管内局になる都府県。「新潟県、長野県」のように「、」で区切る
管内のエリア	0	管内のエリアの数字（例：0）
管内の呼び名	信越	審査結果やLCRで使う、管内の呼び名（例：信越）
# 規約が「信越管内に住所があり、管内で運用する局」なので、住所も確かめる
管内局の決め方	管内に住所があり、管内で運用した局	「管内で運用した局」＝運用地（送ったナンバー）が管内なら管内局（地方コンテストのほとんどはこれ）。「管内に住所があり、管内で運用した局」＝住所も管内であることを確かめる（JA0 VHF）。空なら後のほう
# 規約が「個人局」「社団局」と書いているため
シングルオペ・マルチオペの呼び方	個人／社団	規約の書き方に合わせて選ぶ。「個人／社団」（個人局・社団局）と「シングルオペ／マルチオペ」は意味が違う（ゲストオペで個人局がマルチオペになることもある）。結果・LCRなどに出る言葉と、「規約_種目」の見出し・「規約_部門と表彰」の項目の名前がこの言葉になる（「1. 初期設定」で書き換わる）。空なら「個人／社団」
管内局が送るナンバー	市、郡、区	市・郡・区・都府県支庁から選び、「、」で区切る
# 信越の外の局は都府県支庁のナンバーを送るため
管外局が送るナンバー	都府県支庁	市・郡・区・都府県支庁から選び、「、」で区切る
電力記号を送る	しない	ナンバーの後ろに電力記号（P・L・M・Hなど）を付けるか
チェックログの種目コード	CHECKLOG、CHECK、CL	サマリーシートの種目欄がこれならチェックログ。「、」で区切る。最初のものを「種目の変更」で使う
管外局は管内局とだけ交信できる	する	「する」＝管外局どうしの交信は得点にならない
1交信の得点	1	1交信あたりの得点
重複交信の単位	バンドごと	同じ局との2回目以降を重複とする単位。「バンドとモードごと」なら電信と電話で別に交信できる。「バンドとモード欄ごと」ならログのモード欄（CW・SSB・FM など）が違えば別に交信できる
# 同じ局と電話・電信で交信したとき、電信の交信を残す（委員会の決まり）
重複のときは電信を優先する	する	「する」＝同じ局との重複の交信のうち、ほかの理由で無効にならない交信の中で、いちばん先の電信の交信を残す（電信がなければ、いちばん先の交信）。「しない」・空＝いちばん先の交信を残す
終了の分の交信	時間内	開催期間の終了日時ちょうどの分の交信。「時間内」・空＝時間内（例：終了 12:00 なら 12:00 の交信は有効）。「時間外（時報まで）」＝時間外（12:00 の交信は無効。11:59 まで）
総得点の計算	各バンドの得点の合計×各バンドのマルチの合計	総得点の出し方
同点のとき	最終交信時刻が早い局が上位	同点の局の順位の決め方。「同じ順位にする」＝総得点が同じなら同じ順位
移動表示だけが違う呼出符号	呼出符号の誤り	相手局のログに JA0RL、自局のログに JA0RL/0 のように、移動表示だけが違うときの扱い
運用場所の変更を確かめる	しない	「する」＝1通のログの中で送ったナンバーが途中で変わっていたら「要確認」に出す（開催部門があれば開催部門ごと）。「しない」・空＝確かめない
# JA0 VHFコンテスト用の zLog の DAT
マルチ一覧（zLogのDAT）	http://ja6ycu.in.coocan.jp/ZLOG/ja0vhfi.dat	「マルチ一覧を取り込む」で読む、zLogのマルチ定義ファイルのURL（またはドライブに置いたDATファイルのURL）。管内局用を指定する
登録クラブ一覧のURL	https://www.jarl.org/Japanese/A_Shiryo/A-B_Club/list.htm	「登録クラブ一覧を取り込む」で読む一覧のページ（JARL本部の「登録クラブ一覧」、または支部のページ）。ドライブに置いたHTMLファイルのURLでもよい

# 規約の表彰の決まり（参加局数で表彰する順位が変わる）
表彰	表彰の基準	5局まで1位、10局まで2位、それ以上3位	種目・部門ごとの参加局数（順位に入った局の数。クラブ対抗はクラブの数）と、表彰する順位。例：「5局まで1位、10局まで2位、それ以上3位」、一律なら「3位まで」、参加局数の割合なら「参加10局につき1局、最大6位」（端数は下の「表彰の端数」）。空なら表彰の印を付けない。局長賞は、いつも1位だけ
表彰	表彰の端数	切り上げ	「参加10局につき1局」の書き方のときの端数（例：15局なら、切り捨て＝1位まで、切り上げ・四捨五入＝2位まで）。空なら切り上げ
表彰	局長賞の名前	信越総合通信局長賞	全体で最高得点の1局に出す賞の名前。空なら局長賞はない
表彰	局長賞の局区分	管内局	局長賞の対象の局区分。空なら両方
表彰	局長賞の個人／社団	個人	局長賞の対象。空なら両方
表彰	局長賞の参考に載せる局数	5	局長賞の欄に、参考として上位何局まで載せるか
表彰	エリア別1位も表彰する局区分		この局区分の種目は、上位局のほかにエリア別1位も表彰する。空なら使わない
意見欄	意見欄の案内	電信部門・ジュニア部門に申し込む方は、ここに「電信部門」「ジュニア部門」と書いてください。ジュニア部門は生年月日も書いてください（例：ジュニア部門 生年月日 2010年4月5日）	ログ入力フォームの意見欄の上に出す文。審査は意見欄の「電信部門」「ジュニア部門」の語で申し込みを読む（全角・半角・間の空白は問わない）。空なら出さない
