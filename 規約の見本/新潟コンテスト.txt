# コンテスト審査システム 規約のファイル 形式1
# 規約の見本：新潟コンテスト
# 新潟コンテストの規約（2026年、第26回）から作った例。docs/規約の例_新潟・ギガヘルツ.md の 1.。
# 開催部門（7MHz部門・ハイバンド部門・ローバンド部門）の日時は、審査のファイルの「基本設定」の開催期間1〜3に書きます。
# この見本は、規約の本文から作った例です。毎年、その年の規約の本文で確かめてから使ってください。
# 「#」で始まる行は説明で、読み込みでは読み飛ばします。マスはタブで区切ります（形は README の「規約のテキストファイル」）。
# 読み込むには、審査のファイルのメニュー「コンテスト審査」→「規約をテキストから読み込む」で、このファイルの URL を入れます。
# 「基本設定」（その年の開催期間・開催回など）は、ここには入りません。審査のファイルの「基本設定」に毎年書きます。

項目	値	説明
# サマリーシートのコンテスト名に「新潟」が入っていなければ注意にする
コンテスト名の照合の語	新潟	サマリーシートのコンテスト名に、この語が全部含まれていなければ「注意」にする。「、」で区切る。「ギガヘルツ／GHZ」のように「／」でつないだ語は、どれか1つが入っていればよい
クロスチェックの時刻の許容誤差（分）	5	相手局のログと交信時刻が、前後この分だけずれていても同じ交信とみなす
電信のモード	CW	ログのモード欄がこれなら電信。「、」で区切る
電話のモード	SSB、AM、FM、DV	ログのモード欄がこれなら電話。「、」で区切る
RSTが3桁なら電信とみなす	する	「する」＝モード欄が読めなくても、RSTが3桁（599など）なら電信とみなす
# 県内局は新潟県で運用する局
管内の都府県	新潟県	管内局になる都府県。「新潟県、長野県」のように「、」で区切る
管内のエリア	0	管内のエリアの数字（例：0）
管内の呼び名	新潟県	審査結果やLCRで使う、管内の呼び名（例：信越）
# 規約は「新潟県内で運用する局」が県内局。住所は見ない
管内局の決め方	管内で運用した局	「管内で運用した局」＝運用地（送ったナンバー）が管内なら管内局（地方コンテストのほとんどはこれ）。「管内に住所があり、管内で運用した局」＝住所も管内であることを確かめる（JA0 VHF）。空なら後のほう
# 規約が「シングルOP」と書いているため
シングルオペ・マルチオペの呼び方	シングルオペ／マルチオペ	規約の書き方に合わせて選ぶ。「個人／社団」（個人局・社団局）と「シングルオペ／マルチオペ」は意味が違う（ゲストオペで個人局がマルチオペになることもある）。結果・LCRなどに出る言葉と、「規約_種目」の見出し・「規約_部門と表彰」の項目の名前がこの言葉になる（「1. 初期設定」で書き換わる）。空なら「個人／社団」
管内局が送るナンバー	市、郡、区	市・郡・区・都府県支庁から選び、「、」で区切る
# 県外局は都府県支庁のナンバーを送る
管外局が送るナンバー	都府県支庁	市・郡・区・都府県支庁から選び、「、」で区切る
電力記号を送る	しない	ナンバーの後ろに電力記号（P・L・M・Hなど）を付けるか
チェックログの種目コード	CHECKLOG、CHECK、CL	サマリーシートの種目欄がこれならチェックログ。「、」で区切る。最初のものを「種目の変更」で使う
管外局は管内局とだけ交信できる	する	「する」＝管外局どうしの交信は得点にならない
1交信の得点	1	1交信あたりの得点
# 電話と電信は別の交信として数える
重複交信の単位	バンドとモードごと	同じ局との2回目以降を重複とする単位。「バンドとモードごと」なら電信と電話で別に交信できる。「バンドとモード欄ごと」ならログのモード欄（CW・SSB・FM など）が違えば別に交信できる
# 電話と電信は別の交信なので、優先は使わない
重複のときは電信を優先する	しない	「する」＝同じ局との重複の交信のうち、ほかの理由で無効にならない交信の中で、いちばん先の電信の交信を残す（電信がなければ、いちばん先の交信）。「しない」・空＝いちばん先の交信を残す
# 規約に「時報まで」とあるため（16:00 の交信は 7MHz部門では時間外、ハイバンド部門では時間内）
終了の分の交信	時間外（時報まで）	開催期間の終了日時ちょうどの分の交信。「時間内」・空＝時間内（例：終了 12:00 なら 12:00 の交信は有効）。「時間外（時報まで）」＝時間外（12:00 の交信は無効。11:59 まで）
総得点の計算	各バンドの得点の合計×各バンドのマルチの合計	総得点の出し方
同点のとき	最終交信時刻が早い局が上位	同点の局の順位の決め方。「同じ順位にする」＝総得点が同じなら同じ順位
移動表示だけが違う呼出符号	呼出符号の誤り	相手局のログに JA0RL、自局のログに JA0RL/0 のように、移動表示だけが違うときの扱い
# 開催部門の中で運用場所を変えていないかを確かめる
運用場所の変更を確かめる	する	「する」＝1通のログの中で送ったナンバーが途中で変わっていたら「要確認」に出す（開催部門があれば開催部門ごと）。「しない」・空＝確かめない
# 新潟コンテスト用の zLog の DAT（県内の市郡区と都府県支庁）。https://ja6ycu.in.coocan.jp/ にほかのコンテストの DAT もある
マルチ一覧（zLogのDAT）	https://ja6ycu.in.coocan.jp/ZLOG/niigata.dat	「マルチ一覧を取り込む」で読む、zLogのマルチ定義ファイルのURL（またはドライブに置いたDATファイルのURL）。管内局用を指定する
登録クラブ一覧のURL	https://www.jarl.org/Japanese/A_Shiryo/A-B_Club/list.htm	「登録クラブ一覧を取り込む」で読む一覧のページ（JARL本部の「登録クラブ一覧」、または支部のページ）。ドライブに置いたHTMLファイルのURLでもよい
