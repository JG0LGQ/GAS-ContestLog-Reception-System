# GAS-ContestLog-Reception-System

アマチュア無線コンテストの**ログの受付から審査・結果の公開まで**を、Google のサービス（Google ドライブ・スプレッドシート・Gmail・Apps Script）だけで行うためのスクリプトです。
コンテスト委員会が、自分の Google アカウントに入れて使います。お金のかかるサービスは使いません。

## できること

- **受付**：メールで届いた電子ログと、受付ページ（ログ入力フォーム・ファイルのアップロード）から出されたログを受け付け、自動で返信します
- **審査**：ログを照らし合わせて重複・誤りを見つけ、得点・順位・表彰を出します
- **送信**：LCR（ログチェックレポート）・参加証・前年の参加者への案内メールを送ります
- **公開**：受付局リスト・結果ページ・コンテストレコードを Web に公開します

開発の初めは JA0-VHF コンテストだけに対応するものとして作り始めたため、JA0-VHF コンテストの規約が基本になっています。ですが、「QSO数×マルチ」で得点を計算する方式のコンテストであれば、規約のファイルの書き方で対応できるはずです（見本として、JA0-VHF・新潟・ギガヘルツの規約のファイルを入れてあります）。

## 入っているもの

| ファイル | 中身 | 貼る場所 |
| --- | --- | --- |
| gas/御本尊.gs | 受付・審査・送信のスクリプト | 審査のスプレッドシート（審査_テンプレート） |
| gas/受付ページ.gs | 受付局リスト・ログ入力フォーム・アップロードの Web ページ | 受付ページのスプレッドシート |
| gas/結果ページ.gs | 結果の Web ページ | 結果ページのスプレッドシート |
| gas/レコードページ.gs | コンテストレコードの Web ページ | コンテストレコードのスプレッドシート |
| 規約の見本/ | コンテストごとの規約のテキストファイル（見本は増やしていく予定です） | 「規約をテキストから読み込む」で読み込む |

## 用意するもの

- 委員会の Google アカウント（無料の Gmail アカウント）1つ。個人のアカウントではなく、委員会として新しく作ったものを使います
- 委員それぞれの Google アカウント
- パソコンとブラウザ（Google Chrome など）
- 受付ページ・結果ページを載せる委員会のホームページ（なければ無料の Googleサイト）

## 使い始めるまで（あらまし）

くわしい手順は「導入の手引き」にあります。ここでは流れだけを書きます。

1. 委員会のアカウントで、Google ドライブに親フォルダを作り、その中に「テンプレート」と「公開ページ」のフォルダを作る
2. 「テンプレート」の中にスプレッドシート「審査_テンプレート」を作る
3. 「拡張機能」→「Apps Script」を開き、はじめからある中身を全部消して、「gas」フォルダの「御本尊.gs」の中身を貼り付けて保存する（左上のプロジェクト名も「御本尊」にする）
4. スプレッドシートを読み込み直し、メニュー「コンテスト審査」→「1. 初期設定（シートを作る）」を実行する（初めは承認の画面が出ます。下の「承認の画面について」）
5. 「コンテスト審査」→「規約をテキストから読み込む」で、コンテストの規約のテキストファイルを読み込む
6. 「基本設定」シートに、その年のコンテストの情報（コンテスト名・開催期間など）を書く
7. 「2. マルチ一覧（zLogのDAT）を取り込む」を実行し、「設定の読み込みを確かめる」で誤りがないか確かめる
8. 受付ページ・結果ページ・コンテストレコードのスクリプトを、それぞれのスプレッドシートに貼り、Web アプリとして公開する

次の年からは、テンプレートで「新年度の準備（テンプレートから）」を実行すると、その年のフォルダとファイルができます。

## ファイルの中身をコピーするには

ファイル名を押して開き、中身の右上にあるコピーのボタン（四角が2つ重なった絵）を押すと、中身をまるごとコピーできます。GitHub のアカウントがなくても取れます。

## 規約の見本を読み込むには

「規約をテキストから読み込む」で URL を聞かれたら、「規約の見本」フォルダの中のファイルを開いたときの、ブラウザの上に出ているアドレスをそのまま入れます。

- 見本の中の「#」で始まる行に、規約のどこからその値にしたかが書いてあります
- ほかのコンテストは、いちばん近い見本を読み込んでから、規約のファイルを直してください。直した規約は「規約をテキストに書き出す」でテキストファイルにできます

## 承認の画面について

初めてメニューを使うとき、Google から「このアプリは Google で確認されていません」と出ます。これは、委員会が自分で貼ったスクリプトのときに出るもので、次のように進めます。

1. 「権限を確認」を押し、委員会のアカウントを選ぶ
2. 左下の「詳細」を押し、「（プロジェクト名）（安全ではないページ）に移動」を押す
3. アクセスを求める画面で「すべて選択」にチェックが入っていることを確かめ、「次へ」を押す

スクリプトは、委員会のアカウントのドライブ・スプレッドシート・Gmail を使います。メールは参加者への返信・LCR・参加証・案内メールとして送るだけで、ほかの所へデータを送ることはありません（外のページは、マルチ一覧・登録クラブ一覧・規約の見本を取り込むときに読むだけです）。

## 新しい版にするとき

- Apps Script の画面で前の中身を全部消してから、新しい「.gs」を貼ります
- 貼ったあと「1. 初期設定」を一度実行します（新しい行やシートが足されます。委員が書いた値は消えません）
- その年の審査のファイルと、テンプレートの両方に貼ります
- Web ページのスクリプトは、貼ったあと「デプロイを管理」で新しいバージョンにします（URL は変わりません）
